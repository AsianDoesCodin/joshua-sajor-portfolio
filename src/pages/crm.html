Blue Lotus CRM

The private sales platform my studio runs on: a realtime pipeline, team chat, shift-aware access, a website scanner that writes the call notes, and an API that lets AI agents work deals with the same permissions as staff.

crm.bluelotuscoding.com

Sample data. Every person, company and number on these screens is fictional.

01Problem

A small sales team working hundreds of cold leads needs one source of truth: who owns each deal, what happens next, and who is allowed to change what, and when. Off-the-shelf CRMs were generic, priced per seat and blind to how the studio actually sells.

02Solution

I designed and built a private CRM from the database up. Numbered opportunities move through seven stages with claims, tags, @mentions and a shared calendar. Row Level Security enforces eleven per-member permissions, shift rules lock the workspace outside clocked-in hours, and a Lighthouse-powered scanner turns any prospect's website into problems, pitches and an opener.

03Result

The team works one live pipeline of 1,300+ opportunities. A reload paints from the local cache in about 150 ms instead of 3.4 s, search answers in 110 ms instead of 390 ms, and AI agents claim, schedule and update deals under the same rules as people.

  • 0.15sReload to a full list, down from 3.4 s
  • 110msSearch across every deal, down from 390 ms
  • 11Per-member permissions enforced in Postgres
  • 7Pipeline stages, updated live on every screen

Site scanner → call prep

Runs a full Lighthouse audit in a serverless browser, detects the platform, booking, chat and SEO gaps, then writes the opener and the pitches for the call.

Clock-in and shift rules

Managers set hours, weekdays and a time zone per member. Outside a clocked-in shift, the CRM and the agent API both turn read-only.

Agent API with MCP

A permission-aware Edge Function plus an MCP server, so Claude and other agents can find, claim, schedule and update deals like a teammate.

Realtime, and fast offline

Supabase Realtime pushes every change to every open screen. An IndexedDB cache draws the list instantly and is wiped on sign-out.
