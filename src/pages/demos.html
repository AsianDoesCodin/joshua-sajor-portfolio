04Websites10 live builds2026

Ten sites. Ten design languages.

A live gallery of complete, clickable demo sites for ten kinds of business, each built around the one action that business needs. Hover a screen to scroll the page.

01Problem

Small business owners can't picture what a better website would do for them, and template screenshots don't persuade anyone.

02Solution

Ten complete demos for ten kinds of business, each with its own type, colour and layout system and a working core flow: estimates, checkout, class booking, home search, food ordering, legal intake, service booking, project management, automation and AI.

03Result

Prospects click through a real booking or checkout instead of a mockup. The CRM's call prep links each pitch to the matching demo, so the right example is one tap away on every call.

Stack

  • HTML
  • CSS
  • Vanilla JavaScript
  • Hash routing
  • Browser-local state
  • AI-generated photography
  • Vercel

  1. 01Bold industrial

    FORM Renovation studio

    Problem
    Renovation leads stall at “call us for a quote”.
    Solution
    Condensed capitals, hard edges, safety yellow and a three-step estimate on every page.
    Result
    One clear next step from any page.

  2. 02Modern editorial

    COMMON Online store

    Problem
    Small makers' shops feel generic next to big retailers.
    Solution
    A magazine-style cover, big italic serif, hairline product grids, a slide-out bag and a three-step checkout.
    Result
    Browse to checkout without losing the editorial feel.

  3. 03Soft organic

    STUDIO Class bookings

    Problem
    Class booking lives in a clunky third-party widget.
    Solution
    A live two-week schedule with booking, class packs, rescheduling and cancellation.
    Result
    Booking in under a minute, fully on brand.

  4. 04Dark luxury

    SPACES Real estate

    Problem
    Brokerage sites look premium but bury the search.
    Solution
    Filtered home search, saved homes, photo lightbox, payment calculator, viewing requests and an instant valuation.
    Result
    Buyers and sellers both get a clear next step.

  5. 05Bold playful

    Luna Food ordering

    Problem
    Delivery apps take a cut of every order.

  6. 06Classic authority

    Problem
